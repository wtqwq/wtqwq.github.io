化学小知识合集

发表于 2026-11-22 更新于 2026-11-25 分类于 高三 ， 文化课

与物质世界接壤的湖边；

本文按专题归类。【易错】 为高频陷阱，【核对】 为原笔记转写存疑处，红色文字 为自测中答错的知识点。复习时优先看这三类标记。

一、分散系与胶体

1. 基本概念

  • 分散系 = 分散质 + 分散剂。
  • 胶体粒子一般是分子或离子的聚集体；但淀粉、蛋白质等高分子化合物分子极大，一个分子就是一个胶粒。

2. 胶体的性质

  • 介稳性的主要原因：胶粒吸附带电粒子而带电，同种胶粒带同种电荷，相互排斥，不易聚沉。
  • 带电的是胶粒，胶体（分散系）整体不带电。

3. 胶体的聚沉

  • 应用：江河入海口三角洲的形成、卤水点豆腐。
  • 方法：① 加入电解质溶液；② 加入带相反电荷胶粒的胶体；③ 加热、搅拌。

4. 氢氧化铁胶体的制备

  • 操作：蒸馏水加热至沸腾 → 逐滴加入 5~6 滴饱和 FeCl₃ 溶液 → 继续煮沸至液体呈红褐色 → 停止加热。
  • 【易错】 必须用蒸馏水，不能用自来水——自来水中含电解质，会使胶体聚沉。
  • 【易错】 Fe(OH)₃ 胶粒是分子集合体，故 1 mol Fe³⁺ 完全水解所得胶粒数 < N_A。

二、物质变化与分类

过程 变化类型
煤的液化、气化 化学变化
苯酚的显色反应 化学变化
风化（失去结晶水） 化学变化
潮解 物理变化
同位素之间的转化 不是化学变化
同素异形体之间的转化 化学变化（如 O₃ ⇌ O₂、金刚石 ⇌ 石墨）
  • 绿矾（七水合硫酸亚铁 FeSO₄·7H₂O）呈绿色，灼烧后生成的 Fe₂O₃ 呈红色——对应"本来绿色……烧之则赤"的记载。
  • 醋酸铅 (CH₃COO)₂Pb 是弱电解质（盐中的少数例外）。
  • 【核对】 MgO、Fe₂O₃、Al₂O₃、CuO 与水均不反应，不能直接生成对应的碱。原笔记作"氢氧化物与水反应"，疑为语音转写误差，建议对照教材确认。
  • 【易错】 判断"风化 / 潮解"：结晶水合物失水（如 Na₂CO₃·10H₂O）是化学变化；固体吸水变潮（如 NaOH 固体）是物理变化。

三、离子共存与水解

1. 可以大量共存的典型组合

  • NH₄⁺ 与 CH₃COO⁻ / CO₃²⁻、Mg²⁺ 与 HCO₃⁻：虽能相互促进水解，但水解程度仍然很小，可以大量共存。
  • 通入氨水先生成白色沉淀，氨水过量后沉淀逐渐溶解 → 溶液中含 Ag⁺（生成 [Ag(NH₃)₂]⁺）。

2. 常见不共存离子组合

组合 原因
ClO⁻ 与 NH₄⁺、SO₃²⁻、Al³⁺、Fe²⁺、Fe³⁺、Cu²⁺、S²⁻、CO₃²⁻、OH⁻ ClO⁻ 水解显碱性 + 强氧化性；与 Fe²⁺、SO₃²⁻、S²⁻ 等发生氧化还原，与 Al³⁺、Fe³⁺ 等双水解
Fe²⁺、Fe³⁺ 与 HCO₃⁻、CO₃²⁻ 相互促进水解（双水解）
[Al(OH)₄]⁻ 与 Zn²⁺、Fe³⁺、Al³⁺、NH₄⁺、HCO₃⁻ 双水解或生成沉淀
Al³⁺ 与 [Al(OH)₄]⁻ 相互促进水解生成 Al(OH)₃
  • 【易错】 ClO⁻ 在酸性、碱性、中性条件下均具强氧化性，均能氧化 I⁻、Fe²⁺、SO₃²⁻、S²⁻。
  • 【易错】 Fe³⁺ 遇 SCN⁻ 生成红色配合物使溶液变红，不生成红色沉淀。

四、氧化还原与化合价

  • KCN 中 C 为 +2 价、N 为 −3 价。
  • 金属单质在化学反应中只作还原剂，只失电子（无负价）。
  • 强氧化剂 KMnO₄、K₂Cr₂O₇、K₂FeO₄ 均能将浓盐酸氧化为 Cl₂。
  • 【核对】 低价硫化物多为有色难溶物：HgS 黑或红、FeS 黑、Cu₂S 黑、FeS₂ 金黄。

五、氮的化合物 · 硝酸

  • 稀硝酸与金属反应相对浓硝酸的优点：① 耗酸量少；② 生成污染性物质少。
  • 【易错】 上述是"优点"，不等于氧化性强弱。浓硝酸的氧化性强于稀硝酸，原笔记表述不准确，以教材为准。

六、化学实验基础

6.1 常用仪器与精度

仪器 精度 / 用量限制 关键要点
试管 加热液体 ≤ 容积 1/3 —
蒸发皿 加热液体 ≤ 容积 1/3 蒸发浓缩须用玻璃棒搅拌（未搅拌算错）；大量晶体析出时停止加热
蒸馏烧瓶、圆底烧瓶 加热液体 ≤ 容积 1/3 —
量筒 0.1 mL 无零刻度
滴定管、移液管 0.01 mL 滴定管零刻度在上部
托盘天平 0.1 g 用前调零，用后回零
锥形瓶 — 可组装气体发生器、用于滴定、作蒸馏接收器；烧杯口太大易挥发
容量瓶 — 无零刻度
  • 温度计：测反应混合液温度时，水银球插入液中但不接触容器内壁；测馏分温度时，水银球置于蒸馏烧瓶支管口处。
  • 滴定管：酸式滴定管不能盛碱性溶液；碱式滴定管不能盛酸性溶液和强氧化性溶液。
  • 玻璃棒：过滤时引流；蒸发时搅拌防溅；溶解时搅拌加速。
  • 胶头滴管：不能平放倒置，滴液时不能接触器壁，用后立即洗净再吸取其他药品（滴瓶配套的滴管除外）。
  • 表面皿：作烧杯、蒸发皿等的盖子，用于 pH 试纸变色实验，不能加热。
  • 试剂瓶：一般用磨口玻璃塞；盛碱性试剂用橡胶塞或木塞；橡胶塞不能盛强酸、强氧化性物质和有机试剂（有机溶剂会使橡胶溶胀）。
  • 干燥器：下层装硅胶等干燥剂；定量实验中称取固体后，应将坩埚置于其中冷却。
  • 坩埚：加热固体时，固体必须是干燥的。

6.2 特殊仪器

  • 启普发生器：适用条件为块状固体 + 液体、反应速率适中、不需加热也不大量放热，制取难溶于反应混合液的气体。优点：随开随用，随关随停。【易错】不能制取的常见气体：Cl₂、SO₃、C₂H₂。
  • 索氏提取器：溶剂用量少，萃取效率高。
  • 空气冷凝管：防止温差过大导致的误差。
  • 球形冷凝管（创新装置）：竖立安装于蒸馏装置，使液体充分冷凝回流，提高反应转化率。
  • 克氏蒸馏头（减压蒸馏用）：防止液体冲入冷凝管，液体只能冲入弯管而难以进入冷凝管，确保蒸馏安全稳定。

6.3 药品的取用

  • 粉末状、小颗粒固体：用药匙或纸槽送入试管底部，不能沾在试管口或管壁；块状大颗粒固体：用镊子夹取。
  • 取少量药品用胶头滴管；取较多药品用倾倒法，标签朝向手心；向容量瓶、漏斗中倾倒时用玻璃棒引流。
  • 闻气体用扇闻法：手在瓶口轻轻扇动，只使极少量气体飘入鼻孔。
特殊试剂 取用 / 处理方法
Na、K 镊子取出 → 滤纸吸干表面煤油 → 在玻璃片或白瓷板上用小刀切割 → 剩余部分立即放回原瓶
白磷 镊子夹住，在水下用小刀切割
液溴 通风橱中先捏扁滴管胶头，再伸入下层吸取（上层为水层）；腐蚀性强，防止沾到皮肤

6.4 试纸的使用

  • 检验溶液：试纸放在洁净干燥的玻璃片或表面皿上，用玻璃棒蘸取待测液点在试纸中部，观察颜色变化。
  • 检验气体：先用蒸馏水润湿试纸，再用镊子夹取或粘在玻璃棒一端，置于集气瓶口或导管口处，观察颜色变化。

6.5 仪器的洗涤

  • 洗净标准：内壁附着均匀水膜，既不聚成水滴，也不成股流下。
实验残留 污物 清洗试剂
KMnO₄ 分解实验的试管 MnO₂ 热的浓盐酸
碘升华实验的烧杯 I₂ 酒精
长期存放 FeCl₃ 溶液的试剂瓶 Fe(OH)₃ 盐酸
磷相关实验的试管 磷 稀硝酸
油脂实验的试管 油污 热的碱液

6.6 加热操作

  • 固体加热：试管口应略向下倾斜，防止生成的水倒流引起试管炸裂。先均匀预热，再固定在药品部位加热。加热粉末状固体时，在导管口塞一团棉花防止堵塞导管。
  • 液体加热：先擦干玻璃容器外壁的水，以免炸裂；试管夹夹在中上部约 1/3 处；试管口向上与桌面成 45°，防止沸腾溅出烫伤。

6.7 滴定与其他操作

  • 气密性检查四法：微热法、液差法、滴液法、抽气法。
  • 中和滴定：
    • 蒸馏水洗净的滴定管、移液管，须先用待盛液润洗 2~3 次再盛装试液；润洗时倾斜旋转，使标准液润湿全部内壁。
    • 液面开始在 0 刻度以上 → 先赶走尖嘴部分气泡 → 再调整液面至 0 刻度或以下。
  • 检验蔗糖水解产物：先向水解液中加 NaOH 溶液中和硫酸至碱性，再加银氨溶液或新制 Cu(OH)₂ 悬浊液。
  • 用试管溶解 NaCl 固体时，用拇指堵住试管口左右振荡，而不是上下振荡。

6.8 分离与提纯

方法 适用对象 / 操作要点
过滤 一贴（滤纸紧贴漏斗内壁）、二低（滤纸上缘低于漏斗边缘、液面低于滤纸边缘）、三靠（烧杯靠玻璃棒、玻璃棒靠三层滤纸、漏斗下端靠烧杯内壁）。滤液浑浊需重滤，原因可能是滤纸破损或液面超过滤纸边缘
减压过滤（抽滤） 利用抽气泵使吸滤瓶内压强减小，加快过滤速度、产物更干燥；尖口必须对准抽滤瓶支管口。安全瓶导管左短右长防倒吸；停止时先打开安全瓶活塞通大气，再关抽气泵。不能过滤胶状沉淀和颗粒太小的沉淀（前者透过滤纸，后者形成密实层降速）
蒸发结晶 不蒸干，出现较多晶体时停止加热；适用于溶解度随温度变化不大或减小、且稳定的物质（NaCl、Ca(OH)₂）
冷却结晶 适用于溶解度随温度升高而增大、或不稳定的结晶水合物与铵盐（KNO₃、NH₄Cl）
蒸馏 温度计水银球置于蒸馏烧瓶支管口处；烧瓶内加沸石防止暴沸
减压蒸馏 降低组分沸点，适用于高沸点及受热易分解、氧化、聚合的物质。装置：克氏蒸馏头防冲料；毛细管距瓶底 1~2 mm，引入微小气泡形成气化中心、防暴沸并起搅拌作用
萃取 / 分液 利用溶质在互不相溶溶剂中溶解度差异。水与 CCl₄ 混合时 CCl₄ 在下层（密度大且与水不互溶）；I₂ 在 CCl₄ 中溶解度更大，但加入大量 KI 溶液后 I₂ + I⁻ ⇌ I₃⁻，可反萃取回水层

6.9 实验事故处理

情况 处理方法
少量浓盐酸溅到皮肤 先用干布抹去 → 大量水冲洗 → 涂 NaHCO₃ 溶液
酸液溅入眼中 大量水冲洗，边洗边眨眼
酒精等有机物在实验台着火 用湿抹布、石棉或沙土盖灭，不能用水
浓碱沾到皮肤 大量水冲洗 → 涂硼酸
苯酚液溅到皮肤 酒精冲洗 → 再用水冲洗
误食重金属盐 立即口服蛋清或牛奶
水银洒到桌面 撒硫粉处理
少量火情 可用灭火毯（石棉布）盖灭

K、Na 浸在煤油中
白磷 放在水中，隔绝空气
Li 浸在石蜡油中

氢氟酸 HF 塑料瓶（腐蚀玻璃）

6.11 沉淀（晶体）的洗涤

  • 洗涤液选择：
    • 冰水洗涤：除去表面可溶性杂质，同时降低溶解损耗；
    • 浓盐酸洗涤：除去表面可溶性杂质，降低溶解损耗（利用同离子效应）；
    • 醇（乙醇）洗涤：除去晶体表面水分，易于干燥。
  • 操作：沿玻璃棒向过滤器中注入适量洗涤液，恰好浸没沉淀，待其自然流尽后，重复 2~3 次。
  • 检验是否洗净：取少量最后一次洗涤液于洁净试管中，加入相应试剂检验特征离子。

6.12 反溶剂沉淀法

  • 向溶剂中加入一种与目标产物不溶或微溶的不良溶剂，使目标产物沉淀析出。
  • 常用不良溶剂：烷烃，甚至乙醇。乙醇可降低水的极性，使配合物溶解度下降而沉淀（参见云南 2026 高考第 16 题）。

七、化学反应原理拾遗

1. 热力学与动力学

  • 热力学：回答反应"有没有推动力、能不能发生"，与焓变 ΔH、自由能 ΔG 相关。
  • 动力学：回答反应"有多快、机理如何"，与温度、活化分子浓度、活化能相关，决定反应速率。

2. 影响速率的其他因素

  • 加压提高反应速率，通常因为加压增大气体溶解度，从而提高反应物浓度。
  • 催化剂上的脱附是吸热反应。
  • 反应方程式与反应机理式有区别，注意辨别。

3. 常见气化反应

  • C + H₂O(g) --高温–> CO + H₂
  • CO + H₂O(g) --高温–> CO₂ + H₂

4. 酸性强弱与氧化性

  • 酸性强弱：H₂SO₃ > H₂CO₃ > HSO₃⁻ > HCO₃⁻（据此判断 SO₂ 与 CO₂ 的除杂可行性）。
  • 浓磷酸不是氧化性酸，通常不具有氧化性。

5. 有机反应拾遗

  • 苯环上酚羟基的邻位可被溴取代。

八、碱金属

1. 定义与物理性质

  • 碱金属：元素周期表第ⅠA 族除氢外的所有元素。
  • 银白色金属（铯略带金色光泽），硬度小可用小刀切割。
  • 随原子序数增大：硬度减小、熔点降低（金属键减弱）、密度增大。
  • 反常：钾的密度比钠小。
  • 密度关系：水 > K、Na > 煤油 > Li，故 Na、K 保存在煤油中，Li 保存在石蜡油中。

2. 化学性质

  • 均能与 O₂ 反应：Li 只生成 Li₂O；Na 生成 Na₂O₂；K 燃烧生成复杂氧化物如 KO₂（超氧化钾）。
  • Na 的密度比水小、比乙醇小，但比煤油大；Na 可直接与 Cl₂ 反应生成 NaCl。
  • Na 与部分盐在高温下反应：
    • TiCl₄ + 4Na --高温–> 4NaCl + Ti
    • KCl + Na --高温–> NaCl + K(g)↑（K 沸点低于 Na，以蒸气逸出——制取金属钾的原理）
  • Na 置换乙醇羟基中的氢——用于销毁钠。

3. 钠的制备、保存与用途

  • 制备：电解熔融 NaCl。
  • 保存：少量钠保存在煤油中，大量钠保存在石蜡油中。
  • 用途：Na-K 合金室温呈液态，用作核反应堆传热介质；强还原剂冶炼 Ti；高压钠灯；Na₂O₂ 作漂白剂、消毒剂、供氧剂。
  • 【易错】 钠燃烧不能用水灭火，应用沙土盖灭，不可用泡沫灭火器（会产生 CO₂ 与 Na 反应）。

4. 焰色试验

5. 钠的化合物

  • NaOH：俗称火碱、烧碱、苛性钠。
  • Na₂CO₃ 性质稳定，但结晶碳酸钠（Na₂CO₃·10H₂O）易风化。
  • 【易错】 用澄清石灰水不能鉴别 NaHCO₃ 与 Na₂CO₃ 溶液（两者均生成 CaCO₃ 沉淀）。
  • 用途：Na₂CO₃ 用于制玻璃、制肥皂、合成洗涤剂、造纸、纺织、石油、冶金；NaHCO₃ 用于烘焙膨松、灭火器、治疗胃酸过多、发酵粉。
  • 侯氏制碱法：饱和食盐水 → 先通 NH₃ → 再通 CO₂ → 过滤得 NaHCO₃ → 煅烧得纯碱；母液加食盐粉和 NH₃ → 降温过滤得 NH₄Cl；母液循环使用。循环物质：CO₂ 和饱和食盐水。

九、镁、铝及其化合物

1. 镁

  • Mg 可与 O₂、N₂、CO₂ 反应；【易错】镁着火不能用 CO₂ 灭火。
  • Mg 在空气中燃烧得 MgO 与 Mg₃N₂ 混合物。
  • Mg 加热条件下与水反应生成 Mg(OH)₂ 和 H₂。
  • MgO 熔点高，可作耐火砖；Al₂O₃ 可作耐火坩埚。
  • 水垢中镁的存在形式是 Mg(OH)₂，因其溶解度小于 MgCO₃。

2. 铝

  • Al 在自然界中以化合态存在，无单质；硬度、密度较小，导电导热性和延展性好。
  • 【易错】 Al 即使与过量氨水反应，也只生成 Al(OH)₃，不生成 [Al(OH)₄]⁻（氨水碱性弱）。
  • 向含 [Al(OH)₄]⁻ 溶液中通入过量 CO₂ → Al(OH)₃ + HCO₃⁻；少量 CO₂ → CO₃²⁻。
  • Al³⁺ 与 [Al(OH)₄]⁻ 发生相互促进的水解，生成 Al(OH)₃。

3. 铝土矿与工业炼铝

  • 铝土矿主要成分 Al₂O₃，杂质为 Fe₂O₃、MgO、SiO₂。
  • 碱溶法：加碱 → 过滤 → 加酸 → 过滤 → 通入足量 NH₃ → 过滤出 Al(OH)₃ → 电解。
  • 酸溶法：加盐酸 → 滤液加过量 NaOH、加热 → 过滤 → 通 CO₂ 控制条件生成 Al(OH)₃ → 加热 → 电解。
  • 【易错】 第一步加热过滤的作用是防止形成胶体吸附 Al³⁺。

4. 明矾

  • 化学式 KAl(SO₄)₂·12H₂O，属于复盐；溶于水发生电离，电离方程式不含结晶水（直接写 KAl(SO₄)₂ 电离）。
  • 净水原理：Al³⁺ 水解生成 Al(OH)₃ 胶体，吸附能力强，吸附水中悬浮杂质形成沉淀。

十、铁及其化合物

1. 铁的存在与反应

  • 铁主要以化合态存在，游离态铁存在于陨铁中；银白色固体。
  • Fe + S --加热–> FeS（用红热的玻璃棒引发）；Fe + I₂ --加热–> FeI₂。
  • 3Fe + 4H₂O(g) --高温–> Fe₃O₄ + 4H₂。
  • Fe₃O₄ 俗称磁性氧化铁，不属于碱性氧化物。

2. 铁的氢氧化物

  • Fe(OH)₂ 的氧化：白色絮状沉淀迅速变为灰绿色，最后变成红褐色（被空气中 O₂ 氧化为 Fe(OH)₃）。
  • 制备 Fe(OH)₂ 三法：
    1. 有机覆盖层法：吸有 NaOH 的胶头滴管插入 FeSO₄ 液面以下，液面覆盖苯或煤油（不能用 CCl₄）；
    2. 还原气体保护法：先用 H₂ 排尽空气，再混合亚铁盐与 NaOH，可长时间观察白色沉淀；
    3. 电解法：铁作阳极电解 NaCl 或 NaOH 溶液，液面覆盖苯或煤油。
  • 【易错】 上述溶液均需加热煮沸以除去溶解氧。
  • Fe₂O₃ 红棕色；Fe(OH)₃ 红褐色。

3. 铁离子的检验与转化

  • 【易错】检验 Fe²⁺：不能先加氯水后加 KSCN；也不能将加 KSCN 后的混合液加入足量新制氯水——新制氯水可能氧化 SCN⁻。
  • 转化网络：
    • Fe³⁺ → Fe：被 Al、CO 等还原（**【核对】**原笔记作"氧化成铁单质"，应为还原）；
    • Fe³⁺ → Fe²⁺：被 Fe、Zn、Cu、ZnS、KI 还原；
    • Fe²⁺ → Fe：被 Mg、Al 还原；
    • Fe → Fe²⁺：被 I₂、S 氧化。
  • 【易错】 Fe²⁺ 具强还原性，可被 Na₂O₂、Br₂ 氧化，但不能被 I₂ 氧化。
  • 制备无水 FeCl₃：在 HCl 气流中加热蒸干 FeCl₃ 溶液。

十一、铜及其化合物

  • 铜为紫红色固体，不能被磁体吸引。
  • 常温潮湿空气中与 O₂、CO₂、H₂O 反应生成碱式碳酸铜（绿色）；空气中加热生成 CuO（黑色）；与 Cl₂ 加热生成 CuCl₂，产生棕黄色的烟。
  • 除去 N₂ 中的 O₂：通过红热的铜单质。
  • Cu₂O 在酸性条件下歧化：生成 Cu²⁺ 和 Cu。
  • 碱式碳酸铜受热分解：生成 CuO、CO₂ 和 H₂O。
  • 胆矾 / 蓝矾为 CuSO₄·5H₂O（蓝色晶体）；无水 CuSO₄ 为白色粉末，遇水变蓝。
  • 【易错】 无水 CuSO₄ 只能检验水，不能作水蒸气的吸收剂或用于除杂、干燥。
  • 【易错】 将 CuCl₂ 溶液在蒸发皿中加热蒸干，不能制得 CuCl₂ 固体。

十二、金属材料与冶炼

1. 合金与金属材料

  • 合金：两种或两种以上金属（或金属与非金属）熔合而成的具有金属特性的物质。多数合金熔点低于各成分金属，硬度高于各成分金属。
  • 黑色金属：Fe、Mn、Cr 及其合金；有色金属：黑色金属以外的其他金属及其合金。
  • 钢：分碳素钢（低碳、中碳、高碳）和合金钢。碳含量增加 → 更硬更强，但更脆、难焊、延展性变弱。
  • 铝合金：密度小、强度高、塑性好、易加工；铜合金：青铜（我国最早使用）、黄铜、白铜。

2. 金属的冶炼

方法 适用金属
电解法 K、Ca、Na、Mg、Al
热还原法 Zn、Fe、Sn、Pb、Cu
热分解法 Hg、Ag
其他方法 Pt、Au（游离态富集）
  • 自然界中只有金、铂等极少数金属呈游离态。
  • 冶炼 Mg：电解熔融 MgCl₂，不电解 MgO（MgO 熔点高，耗能大）。
  • 冶炼 Al：电解熔融 Al₂O₃，不电解 AlCl₃（AlCl₃ 是共价化合物，熔融态不导电）；加冰晶石 Na₃AlF₆ 降低 Al₂O₃ 熔点。
  • 铝热反应：制取熔点较高、活泼性弱于 Al 的金属（Fe、Cr、Mn、W），或用于野外焊接钢轨。
  • 炼铁时焦炭除供热外，还提供还原剂 CO；火烧孔雀石炼铜采用焦炭法。
  • 工业制铜：火法炼铜（直接高温加热铜矿，主流）与湿法炼铜（电解质溶液中反应）。
  • 向浸取液中分次加入镀锡铜箔，可减少铜粉覆盖反应物，提高浸取率。

十三、卤素（氯、溴、碘）

1. 递变规律

性质 递变
单质颜色 F₂ 淡黄绿 → Cl₂ 黄绿 → Br₂ 深红棕 → I₂ 紫黑（随原子序数增大逐渐加深）
熔沸点、密度 随原子序数增大逐渐升高 / 增大
氢卤酸性 HF 弱酸；HCl、HBr、HI 强酸
沸点 HCl < HBr < HI；HF 反常高（氢键）
  • Br₂ 深红棕色液体，常温下唯一呈液态的非金属单质，易挥发、有毒，水中溶解度不大（橙色），有机溶剂中橙红色。
  • I₂ 紫黑色固体，易升华，水中溶解度不大（黄色），有机溶剂中紫红色。
  • F₂ 与 H₂ 暗处即爆炸；F₂ 与水剧烈反应生成 O₂ 和 HF。HF 腐蚀玻璃，保存在塑料瓶中。
  • AgBr、AgI 均有感光性、见光易分解：AgBr 用于照相底片、感光纸；AgI 用于人工降雨。

2. 氯及其化合物

  • Cl₂ 易液化。闻 Cl₂ 用扇闻法。
  • Cl₂ 与 H₂ 点燃产生 HCl：苍白色火焰，出现白雾。Cl₂ 可将 P、Si 氧化为 PCl₃（液体）、PCl₅（固体）、SiCl₄；Cl₂ 与 P 反应产生白色烟雾。
  • 【易错】 Cl₂ 通入淀粉-KI 溶液，过量时蓝色消失，是因为 Cl₂ 把 I₂ 氧化成 IO₃⁻，并未体现漂白性。
  • HClO：不稳定，光照分解为 HCl 和 O₂；具强氧化性，可漂白、消毒。氯水现用现配，保存在棕色试剂瓶中。
  • 漂白液有效成分 NaClO，原理：NaClO + CO₂ + H₂O → NaHCO₃ + HClO。
  • 漂白粉有效成分 Ca(ClO)₂，久置失效：Ca(ClO)₂ + CO₂ + H₂O → CaCO₃ + 2HClO，HClO 见光分解。

3. 氯气的实验室制法

  • 原理：MnO₂ + 4HCl(浓) --加热–> MnCl₂ + Cl₂↑ + 2H₂O。
  • 【核对】 必须用浓盐酸，不用稀盐酸（MnO₂ 与稀盐酸不反应）。原笔记作"浓硫酸"，疑为转写误差。
  • 滴加浓盐酸时拨开分液漏斗塞子（或使小孔对齐），便于液体流出；缓缓加热，避免盐酸大量挥发。
  • 除杂：用饱和食盐水除去 HCl。改进装置加长颈漏斗，可检查气密性与是否堵塞（堵塞时液面上升），并观察气体生成速率。
  • 吸收尾气：不能用澄清石灰水（Ca(OH)₂ 含量太少，吸收不完全）。
  • 验满：湿润的淀粉-KI 试纸置于瓶口，试纸变蓝。

4. 卤离子的检验与萃取

  • 未知液中加稀硝酸和 AgNO₃：白色沉淀 → Cl⁻；浅黄色 → Br⁻；黄色 → I⁻。
  • I₂ 与 Na₂S₂O₃ 反应：生成 I⁻ 和 S₄O₆²⁻。
  • 单质碘可用苯或 CCl₄ 萃取，分液后用蒸馏法将碘与有机溶剂分开。

十四、硫及其化合物

1. 硫单质

  • 自然界中既有游离态（火山口附近、地壳岩层），也有化合态（硫化物如黄铁矿 FeS₂、黄铜矿 CuFeS₂；硫酸盐如石膏、芒硝）。
  • 硫俗称硫磺，黄色晶体；水中难溶，酒精中微溶，CS₂ 中易溶。
  • S + H₂ --加热–> H₂S；S + O₂ --点燃–> SO₂（纯氧中蓝紫色火焰）。
  • 3S + 6NaOH → 2Na₂S + Na₂SO₃ + 3H₂O（歧化反应）。

2. 二氧化硫

  • 易溶于水：1 体积水溶解约 40 体积 SO₂；可用排饱和 NaHSO₃ 溶液收集。
  • 【易错】 除去 SO₂ 中混有的 CO₂ 不能用 NaHSO₃ 溶液（酸性 H₂SO₃ > H₂CO₃ > HSO₃⁻ > HCO₃⁻，NaHSO₃ 不与 CO₂ 反应）。
  • SO₂ + CaO --加热–> CaSO₃；SO₂ + 2H₂S → 3S↓ + 2H₂O（归中反应，体现 SO₂ 的氧化性）。
  • 【易错】 SO₂ 使品红褪色，但不能使紫色石蕊褪色（只使其变红）。
  • 制法：Na₂SO₃ + 浓 H₂SO₄；或 Cu + 浓 H₂SO₄ 加热。
  • 【易错】 SO₂ 通入 BaCl₂ 溶液不生成 BaSO₃ 沉淀。

3. 三氧化硫与漂白剂

  • SO₃ 常温下为液态，标况下为固态；具酸性氧化物通性（与 CaO、Ca(OH)₂ 反应生成 CaSO₄）。
  • 漂白剂三类：
类型 代表物 特点
氧化性 HClO、NaClO、Ca(ClO)₂、Na₂O₂、H₂O₂、O₃ 无选择性、不可逆、持久
加合性 SO₂ 可逆、不持久、有选择性
吸附型 活性炭 物理变化，吸附色素
  • 脱硫三法：① 钙基固硫法（生石灰与含硫煤混合燃烧）；② 氨水脱硫法；③ 钠碱脱硫法（NaOH、Na₂CO₃ 吸收）。

4. 硫酸

  • 纯硫酸为无色、粘稠、油状液体，沸点极高。
  • 稀释：将浓硫酸沿器壁慢慢注入水中，并用玻璃棒不断搅拌。
  • 三大特性：
    • 吸水性：作干燥剂，但不干燥 H₂S、HBr、HI、NH₃；针对液态水、水蒸气、结晶水（使胆矾变白）；
    • 脱水性：针对有机物，按 2:1 脱去 H、O（使蔗糖变黑）；
    • 强氧化性：常温使 Fe、Al 钝化（可用铝/铁槽车运装）；Zn + 浓 H₂SO₄ --加热–> ZnSO₄ + SO₂；Zn + 稀 H₂SO₄ → ZnSO₄ + H₂。
  • 工业制法：煅烧黄铁矿（FeS₂ + O₂ --高温–> Fe₂O₃ + SO₂）→ 净化干燥 → 催化反应室（400~500 ℃、常压、催化剂）→ 吸收塔（98% 浓 H₂SO₄ 吸收得发烟硫酸）→ 稀释至 98%。

十五、海水资源的利用

总原则：海水中 Mg、Br、I 均以化合态存在且含量低，需先富集再提取。

1. 氯（氯碱工业）

海水 → 粗盐 → 精制饱和食盐水 → 电解 → Cl₂ + H₂ + NaOH。

2. 镁

贝壳煅烧得 CaO → 加水成石灰乳 → 引入海水沉淀池得 Mg(OH)₂ → 盐酸酸化浓缩得 MgCl₂·6H₂O → 在 HCl 气氛中脱水得 MgCl₂ → 电解得 Mg + Cl₂。

3. 溴

海水 → 粗盐 → 苦卤 → 硫酸酸化 → Cl₂ 置换出 Br₂ → 热空气吹出 → SO₂ 吸收 → Cl₂ 再氧化得溴水混合物 → 蒸馏 → 冷凝分离得液溴。

4. 碘

干海带灼烧成灰 → 浸泡得悬浊液 → 过滤 → 通入适量 Cl₂ → 加 CCl₄ 或苯萃取分液 → 蒸馏得晶体碘。

十六、常见俗名与物质颜色

1. 俗名对照

3. 铬与钒拾遗

  • 铬酸根与重铬酸根在水中可相互转化：2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O。
  • 【核对】 Cr₂O₃ 和 Cr(OH)₃ 呈两性（原笔记作"氧化铬"，按常见教材为三氧化二铬 Cr₂O₃，建议确认）。
  • V₂O₅ 既能溶于强碱又能溶于强酸。【核对】VO₂⁺（V 为 +5 价）具强氧化性，易被还原为 VO²⁺（V 为 +4 价）——原笔记两处均写作"VO₂⁺"，疑为转写遗漏价态标注。
